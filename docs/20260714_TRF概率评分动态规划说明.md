# 20260714 TRF 概率评分动态规划说明

## 目的

本版本将上一版三状态动态规划中的固定奖励/惩罚，替换为受 TRF 思想启发的概率对数似然比评分。目标是先稳定识别连续、高密度的主要重复段，再把单独散落在复杂序列中的 CAG/GCC 三联体保留为复杂序列，而不是误计为重复次数。

本程序不是 Tandem Repeats Finder（TRF）的复刻，也没有调用 TRF 可执行文件。它借用了 TRF 对匹配概率、插入/缺失概率和连续重复证据的统计建模思想，并将其放入当前的 CAG-like、GCC-like、插入/复杂序列三状态动态规划框架。

## 评分模型

- motif 匹配概率 `pM = 0.80`。
- 插入/缺失概率 `pI = 0.10`。
- 背景碱基概率为 `0.25`。
- 从复杂序列进入重复状态的先验概率为 `0.02`。
- CAG-like 与 GCC-like 状态互换的先验概率为 `0.01`。
- motif 发射分数按逐碱基对数似然比计算：`log(P(碱基|motif) / 0.25)`。
- 状态转换使用先验几率的对数值。进入一个重复段需要累积足够的连续 motif 证据，因此孤立 motif 通常不足以单独成环。

后处理仍要求一个可视化重复环至少满足：

- 连续重复单元不少于 4 个；
- 主体核心不少于 5 个重复单元；
- 重复密度不少于 75%；
- 最多允许 12 bp 的局部插入被并入相邻重复 block。

## 结果

共分析 47 条路径，所有路径都得到 6 个 block：

1. 前导复杂序列；
2. 前段 GCC-like 重复；
3. CAG-like 主重复；
4. 75 bp 中央复杂序列；
5. 后段 GCC-like 重复及局部插入；
6. 尾部局部插入。

概率评分结果为：

- CAG-like：19–32 个重复单元；
- GCC-like 总计：29–36 个重复单元；
- 变异 motif：13–15 个；
- 后段 GCC-like：14–21 个重复单元；
- 17/47 条路径相较固定评分版发生了 block 签名变化，主要来自前段 GCC-like 边界多纳入 1 个有连续证据的变异 motif；
- 中央复杂区在两种评分模型中均为 75 bp，未被散落 motif 切碎。

## 输出文件

- `20260714_IRF2BPL_TRF概率评分_路径汇总.tsv`：每条路径的总次数、变异数和 block 签名。
- `20260714_IRF2BPL_TRF概率评分_block明细.tsv`：每个 block 的 motif 一致性、TRF 对数似然分数、变异和插入序列。
- `20260714_IRF2BPL_TRF概率评分_主体motif证据.tsv`：主要 motif 的路径级证据。
- `20260714_IRF2BPL_TRF概率评分_评分模型汇总对比.tsv`：固定评分与概率评分的汇总比较。
- `20260714_IRF2BPL_TRF概率评分_逐路径评分对比.tsv`：逐路径比较边界与次数变化。
- `20260714_IRF2BPL_TRF概率评分_状态路径图.gfa`：按 motif/变异/插入节点表示的 GFA。
- `20260714_IRF2BPL_TRF概率评分_block图.png`：47 条路径的 block 总览。

## 验证

- 47 条路径均通过原序列与 atom 序列的逐碱基重建检查。
- 47 条路径均通过原序列与 block 序列的逐碱基重建检查。
- 所有被保留为重复环的 block 均满足最小重复次数和重复密度阈值。
- GFA 中每条 `P` 路径按节点序列拼接后与对应 VNTR 区间完全一致。

## 使用

在仓库根目录执行：

```powershell
python -B "程序\20260714_TRF概率评分动态规划VNTR分解.py"
```

可通过命令行参数修改输入 GFA、输出目录和文件名前缀；评分参数集中定义在程序顶部，便于下一轮用更多位点做参数校准。
