# 20260825 P3：半马尔可夫概率分解与 APG 验证

## 目标

本版解决方案文档中的 P3“从固定 DP 到半马尔可夫概率模型”。P1 提供唯一侧翼和共识重复边界，P2 提供 de novo primitive motif 字典与无损 token；P3 不再仅靠固定 run 阈值决定 block，而是从训练路径学习发射、转移和持续长度参数。

当前实现包括：

- 按路径确定性划分 train/tune/test，概率参数只使用训练路径。等权数据使用固定哈希；可选的后缀权重模式同时约束代表路径数和有效权重接近 60/20/20，且不会把同一等位型拆到多个集合。
- 学习每个 motif family 的 exact/variant 发射率、block copy-number 均值和标准差、局部插入长度，以及状态转移概率。
- 用显式 duration probability 约束 repeat block，孤立 motif 不会自动成段。
- 用 k-best Viterbi 输出最优和第二优分解，用半马尔可夫前向后向输出逐 token posterior。
- 为每个 block 输出 segment posterior、token posterior、95% 边界区间和 high/moderate/low 置信度。
- 短且完全由已选字典精确解释的 motif-like background 会重新 token 化；长复杂区不做这种提升。
- 输出位置特异 P3 GFA、TSV 和 PNG，并继续逐碱基验证全部路径。

## 概率含义与限制

当前输入是 assembly GFA，没有原始 HiFi/ONT reads，因此本版状态为 `assembly_only_probabilistic`：

- posterior 表示“给定 P1/P2 与训练路径参数时，哪种序列分解更受模型支持”。
- posterior 不能证明某个变异是真实生物学变异，也不能替代 read support。
- HiFi/ONT 分平台错误模型、替换/indel 概率和 read-backed 真伪判定仍属于 P4。
- P2 motif 字典由全队列发现；P3 的概率参数严格按 train/tune/test 分开。若要做完全无泄漏 benchmark，后续需在每个训练折内重新发现 motif 字典。

## APG P1/P2 审计

输入：`APG + Refs`，共 28 条代表路径。

- P1：左右 21 bp 唯一侧翼均为 28/28，内部边界 28/28，GFA 重建 28/28；外部边界确认仍为 0/28，因此边界状态只能解释为 `provisional_internal_consensus`。
- P2：AGC 与 CCG 两个 3 bp family 均支持 28/28；MDL 从 14096 降到 8987 bits。
- P2：27 条路径为 3 个 block；`seq12_1.0` 被分成 4 个 block。
- `seq12_1.0` 的前两个 CCG block 各 6 copies，中间夹着 12 bp `GCAGCAGCGGCG`，属于同一位置主体被短复杂片段切断，而不是第四个稳定位置环。
- APG FASTA 是 28 条去重代表序列，而路径名末尾形如 `_158.0` 的值之和为 319.5。若该后缀确为上游样本频数，按 28 条路径等权学习会偏高估罕见等位型；P3 因此提供显式 `--path-weight-mode suffix`，但该字段语义仍应由 APG 生成流程确认。
- P1/P2 两张 PNG 无遮挡或坐标错位；P2 图中 `seq12_1.0` 左侧绿色 block 的断裂与 TSV 一致。

## APG P3 结果

- 数据划分：17 train、6 tune、5 test；后缀有效权重分别为 202、62.5、55，总计 319.5。
- 学习持续长度：AGC family `23.90 +/- 2.00` copies；CCG family `16.85 +/- 2.00` copies。
- 调参集选择 duration weight `0.5`。
- 28/28 路径均得到 3 个位置 block，共 84 个 block。
- GFA 为 29 个节点、43 条边，显式位置环为 R1/R2/R3；28/28 路径精确重建。
- 3 个区块为 low confidence，集中在较长 AGC block 的右边界；它们被保留并报告区间，而不是硬性裁成训练均值。

`seq12_1.0` 的 P3 分解：

| block | family | 区间 | copies | variant | 局部穿插 | 置信度 |
|---|---|---:|---:|---:|---|---|
| R1 | CCG | 258-306 | 14 | 2 | `276:GCA;279:GCA`，6 bp AGC-family interruption | high |
| R2 | AGC | 306-378 | 24 | 6 | 无 | moderate |
| R3 | CCG | 453-511 | 18 | 7 | `492:GAAC`，4 bp | moderate |

原 12 bp 片段按 3 bp 重读为 `GCA,GCA,GCG,GCG`。前两枚 GCA 作为短 AGC-family 穿插保留，后两枚 GCG 恢复计入 CCG 主体，因此 R1 从两个 6-copy 小段改为一个 14-copy block，而不是简单把整段吞并成未知序列。

`seq12_1.0` 在最终频数约束划分中属于 train。该路径的修复规则由通用的短 motif-like background 重解析实现，并有独立合成测试覆盖；但不能把它作为完全独立的 held-out 成功案例。完全无泄漏评估仍需在训练折内重跑 P1/P2 motif 发现。

## 输出

- `*_学习参数.tsv`：训练路径估计的发射、duration 和转移概率。
- `*_调参选择.tsv`：duration weight 的调参集比较。
- `*_训练调参与留出划分.tsv`：路径角色、固定哈希及可选路径权重。
- `*_逐路径token后验.tsv`：P3 状态、发射子状态、各状态 posterior 和熵。
- `*_逐路径P3_repeat区块.tsv`：copy、variant、插入、posterior、边界区间和置信度。
- `*_最优与第二优分解.tsv`：完整状态路径、分数差和路径 posterior。
- `*_分组评估.tsv`：train/tune/test 分组检查。
- `*_P3半马尔可夫多环图.gfa`：位置特异概率多环图。
- `*_P3概率区块总览.png`：学习持续长度和逐路径概率区块。
- `*_P3验证汇总.tsv`：重建、环、posterior 和整体 QA。

## Linux 验证

```bash
conda activate vntrmap
bash "程序/20260825_Linux服务器P3完整验证.sh"
```

脚本使用 HPRC 基线执行 P3、运行 P3 回归测试、核对 47/47 重建与 R1/R2/R3，并生成 SHA-256 清单。

APG 使用现有 P1/P2 结果时，直接向 P3 程序提供 APG 的 GFA、P1 边界、P2 字典、token 和 block 文件；不能使用固定检查 47 条路径的 HPRC 验证脚本作为 APG 判定器。

若已确认 APG 路径名最后一个下划线后的数字就是样本频数，运行 APG 时增加：

```bash
--path-weight-mode suffix
```

若该后缀不是频数，应保持默认 `--path-weight-mode equal`，不能把后缀加权结果用于群体参数解释。
