# 20260714 TRF 思想多环 VNTR 试验

## 版本定位

本版本保留 `20260714_三状态动态规划VNTR分解与图建模.py` 及其结果，新增一个独立试验程序。程序吸收 TRF 的周期候选、共识 motif、匹配率、插入缺失率和冗余周期筛选思想，但不是 TRF 官方程序的重新实现，也不依赖外部 TRF 可执行文件。

## 参数

- 主体锚点最少连续复制数：5。
- 独立环最少连续复制数：4。
- 最低重复密度：75%。
- 可合并的局部插入：不超过 12 bp。
- 候选周期：1-18 bp。
- TRF 式比对权重：匹配 `+2`、错配 `-7`、插入缺失 `-7`。

连续 3 次的片段不建立独立环。当前数据中，中央复杂区远离主体的偶然 run 最长为 3 次，因此该规则能够阻止复杂序列产生系统性假环。

## TRF 式周期候选

对动态规划确认的每个重复块测试多个候选周期。每个周期输出：

- 复制次数。
- 多数规则共识序列。
- 与共识的碱基一致率。
- 插入缺失率。
- 相同 2-mer 在该周期距离上的支持率。
- 匹配、错配和插入缺失加权得分。

如果多个周期的一致率相差不超过 2%，优先选择更短的原始周期；跨路径目录再使用多数路径支持的周期和路径方向上的共识 motif，避免把 `CAG` 显示成循环旋转形式 `AGC`。

## 位置特异多环结构

第一段和第三段虽然都是 GCC-like，但使用不同的节点命名空间：

`left flank -> L1_GCC -> L2_CAG -> complex -> L3_GCC -> right flank`

- `L1`：GCC-like，11-15 次，跨路径共识周期为 `GCG`。
- `L2`：CAG-like，19-32 次，跨路径共识周期为 `CAG`。
- `L3`：GCC-like，14-21 次，跨路径共识周期为 `GCC`，包含 7 bp 局部插入。

中央复杂区为 75 bp，其中的零散 1-3 次周期命中不计入任何环。

## GFA 约定

- `L1_M_`、`L2_M_`、`L3_M_`：各位置环的精确 motif 节点。
- `L1_V_`、`L2_V_`、`L3_V_`：只属于对应环的变异 motif 节点。
- `L3_INS_`：第三环内部的显式插入。
- `B*_INS_`：侧翼或环之间的复杂序列。
- `LC` 标签：节点所属的 loop/block 实例。
- `PS` 标签：观察到该连接的路径转换次数。
- `P` 记录：逐次列出真实 motif 遍历；同一环节点连续出现次数即该路径的复制次数。

这种表达避免第一和第三 GCC-like 区域在图中被错误合并成一个全局 GCC 环。

## 验证要求

1. 47 条路径的 GFA 节点序列必须无损重建所选 VNTR 区域。
2. 每条路径必须稳定包含 L1、L2、L3 三个位置特异环。
3. 每个独立环至少 4 个单元且重复密度不低于 75%。
4. GFA 必须分别存在 L1、L2、L3 的自环，不能只有一个共享 GCC 自环。
5. TSV、GFA 和两张 PNG 中的复制次数范围必须一致。
