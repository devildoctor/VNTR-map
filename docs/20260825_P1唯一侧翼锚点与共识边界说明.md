# 20260825 P1：唯一侧翼锚点与共识边界

## 目标

本版开始解决“术语和真实边界不统一”问题，不修改 20260714 的 motif 分解、循环拓扑和路径重建逻辑。新增的数据层明确区分：

- 同源搜索窗口：由跨路径唯一的左右 flank 限定。
- repeat 共识边界：由多个方法在同源窗口内共同支持。
- 边界不确定区间：允许在一个主体 motif 长度内浮动。
- 术语：`TR` 是上位概念，结构类别使用 `STR-like`、`VNTR-like` 或 `complex/mosaic TR`。

所有坐标均为 `0-based, half-open`。

## 当前实现

程序：`程序/20260825_P1唯一侧翼锚点与共识边界.py`

1. 从 47 条 GFA 路径重建序列。
2. 在主体重复两侧搜索 21 bp cohort anchor；候选必须具有足够序列复杂度、位于重复证据之外至少一个 motif，并在跨路径统计中优先满足唯一性和近邻性。
3. 内部边界证据分为三个方法族：
   - `motif_run`：连续 motif seed。
   - `probabilistic_dp`：TRF 概率评分三状态动态规划。
   - `periodicity_loops`：周期候选和位置特异循环。
4. 起点和终点分别寻找“至少两个方法族、差异不超过一个 motif”的最大支持簇；未进入支持簇的方法仍保留为分歧证据。
5. 根据 motif 周期、motif family 数量、复杂间隔和插入情况输出结构术语。
6. 在正式多环 GFA 的 P 行加入边界、置信区间、锚点、方法数和术语标签，不改变节点序列与路径重建。

## 运行

```bash
conda run -n vntrmap python -u \
  "程序/20260825_P1唯一侧翼锚点与共识边界.py" \
  --input "测试数据/IRF2BPL.HPRC.fa.3034e58.11fba48.904d69e.smooth.final.gfa" \
  --outdir "outputs/IRF2BPL/20260825_P1唯一侧翼锚点与共识边界" \
  --prefix "20260825_IRF2BPL_P1唯一侧翼锚点与共识边界"
```

## 输出

- `*_唯一侧翼锚点.tsv`：每条路径的锚点坐标、出现次数、方向位置和 cohort 支持率。
- `*_边界方法证据.tsv`：每个方法给出的起止位置及是否落在唯一 flank 之间。
- `*_路径边界共识.tsv`：共识边界、一个 motif 范围内的置信区间、支持方法和状态。
- `*_术语分类.tsv`：统一的 TR 上位术语和结构类别。
- `*_路径序列.fa`：供 Linux 上的 TRF、MotifScope、uTR/vamos 重新检测。
- `*_外部边界证据模板.tsv`：外部检测结果的标准输入格式。
- `*_P1边界标注多环图.gfa`：带 P1 边界标签的多环 GFA。
- `*_边界共识总览.png`：逐路径锚点、同源窗口、共识区间和不确定区间。
- `*_P1验证汇总.tsv`：唯一锚点、方法支持、术语和无损重建统计。

## GFA 新增标签

| 标签 | 含义 |
| --- | --- |
| `RS/RE` | repeat 共识起点/终点 |
| `SL/SH` | 起点不确定区间下界/上界 |
| `EL/EH` | 终点不确定区间下界/上界 |
| `LA/RA` | 左/右 cohort anchor 起点 |
| `BM` | 支持边界的总方法族数量 |
| `EM` | 外部方法数量 |
| `BT` | 边界状态 |
| `TT` | 结构术语 |

## 外部方法接入

当前结果状态为 `provisional_internal_consensus`。要升级为 `confirmed_multi_tool`，需要在 Linux 上至少加入一个外部方法结果。

外部 TSV 必须包含：

```text
path  method  start_bp  end_bp  motif  source
```

其中前四列必需，坐标必须转换为 `0-based, half-open`。可以重复传入多个文件：

```bash
conda run -n vntrmap python -u \
  "程序/20260825_P1唯一侧翼锚点与共识边界.py" \
  --external-evidence trf_boundary.tsv \
  --external-evidence motifscope_boundary.tsv
```

## 当前限制

- 三类内部证据仍共享现有 CAG/GCC motif 先验，所以只能称为内部共识，不能替代独立工具确认。
- 本版先解决位点同源窗口、边界字段和术语混用；de novo motif 字典属于 P2。
- 外部工具坐标必须先统一到重建路径坐标，不能直接混用参考基因组坐标或 1-based 闭区间。
