# 20260713 不规则 VNTR 区域建模说明

本版目标是从 PGGB GFA 中重新识别每条 path 自己的 VNTR 区域，并把不完全规则的重复结构拆成可解释的 block。

## 文献和工具启发

- Tandem Repeats Finder 的核心启发是：真实 tandem repeat 可以是不完全匹配的，检测时不能只接受严格相同的复制单元，而要考虑替换、插入、缺失造成的近似重复。
- TRGT/TRVZ 的核心启发是：长读长上的 tandem repeat 不能只输出长度，还应该输出 sequence composition、mosaicism 和可视化结果。这个项目目前没有直接调用 TRGT，但输出口径借鉴了这种“组成 + mosaic + 图形”的方式。
- NTRFinder 的核心启发是：重复区可能出现两个或更多不同 motif 互相穿插，也就是 nested/compound tandem repeat；这类区域不应该被强行解释成一个单一 motif 的循环。

## 本版模型

脚本：

`程序/20260713_不规则VNTR区域自动分解与图建模.py`

输入：

`测试数据/IRF2BPL.HPRC.fa.3034e58.11fba48.904d69e.smooth.final.gfa`

输出目录：

`outputs/IRF2BPL/20260713_不规则VNTR区域自动分解`

## 算法步骤

1. 对每条 path 重建完整序列，并保留每个碱基对应的 PGGB 节点。
2. 用滑动窗口寻找 repeat-dense 区域，而不是直接使用固定节点区间。
3. 在候选区间内按原始图节点切分 sequence piece。
4. 对每个 piece 统计 exact motif 组成：`CAG/CAA` 归为 `CAG_like`，`GCG/GCC/GCA/GCT/GGC` 归为 `GCC_like`。
5. 按 piece 的组成和插入长度合并成 path-specific block。
6. 输出 path-specific GFA、block 明细 TSV、path 汇总 TSV 和 PNG。

## Block 类型

- `pure_repeat`：基本由同一类 repeat motif 连续组成。
- `interrupted_or_variant_repeat`：重复为主，但内部有插入或不规则片段。
- `split_or_interrupted_repeat`：同一类 repeat 被短插入、检测断点或图节点切分拆开，重新合并后标记为这一类。
- `compound_mosaic`：同一个 block 内有两类 repeat motif 共同出现，例如 CAG-like 与 GCC-like 混合。
- `inserted_sequence`：低 repeat 密度插入片段。

## 重要解释

`mixed_units` 不是一个单独循环的次数，而是 compound/mosaic block 内部能识别出来的 exact motif 组成数。它用于描述复合重复区的组成复杂度，不应和单纯 repeat loop copy number 混为一谈。

当前版本为了避免误把 GC-rich coding sequence 都当作变异 motif，只统计 exact motif；疑似 variant 先通过 `inserted_bp` 和 `interrupted/split` block 表示。下一版可以在每个 block 内再加入更严格的编辑距离分解，例如只把“被同一 motif run 两侧夹住的 3 bp 差 1 碱基片段”记为 variant。
