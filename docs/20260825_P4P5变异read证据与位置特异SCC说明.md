# 20260825 P4/P5：变异 read 证据与位置特异 SCC 循环图

## 本版解决的问题

P4 将“assembly 中观察到的差异”和“原始 reads 已验证的变异”严格分开。P5 不再把聚合边或相同 motif 序列直接当作同一个环，而是只根据真实路径邻接建立图，再计算 SCC 与 condensation DAG。

## P4：真实变异与测序错误

P4 从 P3 的 `variant_motif` 与 `local_insertion` 状态生成逐路径 assembly 事件，包括：

- motif substitution、motif indel；
- 非 motif 局部插入；
- 其他 motif family 穿插；
- 事件坐标、block 内偏移、编辑脚本、P3 posterior、block confidence 和跨路径 recurrence。

没有 read evidence 时，所有事件只能标为 `assembly_only_unvalidated`。跨 assembly 复现会被报告，但不会被自动提升成真实变异。

### Read evidence 输入

`*_P4_read证据模板.tsv` 每个 assembly 事件提供一行待填写模板。实际输入时，每个 event/read 使用一行，字段为：

- `event_id`、path、repeat block、事件坐标和事件类型；
- `read_id`、platform、strand；
- MAPQ、base quality；
- 是否跨越目标重复区 `spanning`；
- 是否支持该事件 `supports_event`；
- 证据来源/caller。

默认高置信阈值为：至少 5 条高质量 spanning reads，其中至少 3 条支持事件，支持比例至少 0.20，并且正负链均有支持。阈值均可由命令行修改，正式 HiFi/ONT 分析前应在平台 truth set 上校准。

P4 状态：

- `read_backed_high_confidence`：质量、spanning、支持数、比例和方向均通过；
- `uncertain`：有 read 证据，但未同时通过所有阈值；
- `error_like`：覆盖充分但缺乏高质量支持，或支持仅来自低质量 reads；
- `assembly_only_unvalidated`：没有 read 证据。

P4 不直接从 BAM 猜测事件归属。应先使用 GraphAligner、PanAligner 或位点 caller 将 reads 对齐/分型，再把逐 read 判定写入模板。这样能明确区分“比对步骤”和“证据分级步骤”，并保留可审计记录。

## P5：位置特异循环与图论检查

P5 重新扫描 GFA 的每条 P path，并仅保留至少被一个真实路径邻接支持的边。随后：

1. 对有向 handle graph 运行 Tarjan SCC。
2. 用 `LC` 位置标签判断 SCC 属于 R1、R2、R3 或背景。
3. 将 SCC 压缩成 condensation graph，并验证其为 DAG。
4. 检查是否有 SCC 同时包含两个 repeat location。
5. 检查每条路径的 repeat location 是否出现逆序。
6. 统计每条边的 path support 与总 traversal count。
7. 在 motif-family token 层检测严格重复的 AB、ABC 等高阶周期。
8. 在 condensation DAG 中检测分支后重新汇合的 bubble 候选。

同一 motif 即使序列完全相同，只要位置标签不同，就属于不同节点和不同 SCC。ABAB 若由真实路径重复支持，会自然形成 `A→B→A` 的多节点 SCC，而不是两个互不约束的自环。

## 当前验证结果

### HPRC 47 条路径

- P4：755 个 assembly 事件；无 reads，因此 755 个均为 assembly-only；GFA 重建 47/47。
- P5：34 个节点、47 条 path-supported edges、25 个 SCC。
- 3 个循环 SCC 分别对应 R1/R2/R3；跨位置循环为 0。
- condensation DAG 有 26 条边；路径逆序为 0；GFA 重建 47/47。

### APG 28 条代表路径

- P4：450 个 assembly 事件；无 reads，因此 450 个均为 assembly-only；GFA 重建 28/28。
- P5：29 个节点、43 条 path-supported edges、18 个 SCC。
- 3 个循环 SCC 分别对应 R1/R2/R3；跨位置循环为 0。
- condensation DAG 有 17 条边；路径逆序为 0；GFA 重建 28/28。
- 未发现至少两条路径共同支持的严格 AB/ABC 高阶周期。

## 输出解释

P4：

- `*_P4组装事件与read判定.tsv`：正式事件目录和最终证据状态。
- `*_P4_read证据模板.tsv`：下一批 reads/caller 结果的输入模板。
- `*_P4_read证据汇总.tsv`：逐事件 read 数、方向、质量和支持比例。
- `*_P4变异证据标注图.gfa`：不改变路径序列，只增加 P4 标签。
- `*_P4事件证据总览.png`：事件位置、类型与证据状态。

P5：

- `*_P5_SCC目录.tsv`：SCC 节点、位置、family、路径支持和循环分类。
- `*_P5_压缩DAG.tsv`：SCC 之间的有向无环关系。
- `*_P5_边路径支持.tsv`：每条边的颜色/path set 与 traversal count。
- `*_P5_逐路径环遍历.tsv`：每条路径、每个位置环的节点与 SCC 遍历统计。
- `*_P5_bubble候选.tsv`：压缩图中的分支汇合候选。
- `*_P5_高阶循环候选.tsv`：AB/ABC 等 family-level 周期。
- `*_P5位置特异SCC循环图.gfa`：只含真实路径支持边的正式图。
- `*_P5_SCC与路径次数总览.png`：外层 DAG 与逐路径 copy number。
