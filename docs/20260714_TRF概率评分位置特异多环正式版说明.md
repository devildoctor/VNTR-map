# 20260714 TRF 概率评分位置特异多环正式版说明

## 本版目标

本版把 TRF 概率评分动态规划得到的真实 VNTR block，转换为位置特异的多环 GFA。重点不是把所有路径的同类 motif 合并成一个总环，而是在整张图中固定表示三个不同位置的重复环，并在每条路径上记录各环自己的循环次数、变异 motif 和插入碱基。

## 分析流程

1. 使用 `pM=0.80`、`pI=0.10` 的概率对数似然动态规划，把序列分解为 CAG-like、GCC-like、插入/复杂序列三类状态。
2. 仅保留至少 4 个重复单元且重复密度至少 75% 的独立重复环；主要重复核心要求至少 5 个单元。
3. 对每个重复 block 搜索 1–18 bp 的周期候选，计算一致性、indel rate、相邻 tuple 支持率和 TRF 风格比对分数。
4. 先由全部 47 条路径为 L1、L2、L3 分别投票确定全局主体周期，再按该周期重选每条路径的分解候选。
5. 长周期组合仍保存在候选 TSV 中，但不允许它覆盖全体路径共同支持的 3 bp 主体 motif。
6. 在 GFA 中为 L1、L2、L3 使用独立节点命名空间；即使 L1 与 L3 都属于 GCC-like，也不会被合并为同一个环。

## 正式结构

| 位置环 | 类型 | 主体 motif | 路径支持 | 重复次数 | 变异 motif | 插入 |
| --- | --- | --- | ---: | ---: | ---: | ---: |
| L1 | GCC-like | GCG | 47/47 | 12–16 | 1–3 | 0 bp |
| L2 | CAG-like | CAG | 47/47 | 19–32 | 5–7 | 0 bp |
| L3 | GCC-like | GCC | 47/47 | 14–21 | 5–7 | 7 bp |

三个环之间的非重复结构为：

- 左侧复杂序列：24–27 bp；
- L2 与 L3 之间的中央复杂序列：75 bp；
- L3 后的尾部序列：8 bp。

因此每条路径的主体结构均为：

`左侧复杂序列 -> L1(GCG) -> L2(CAG) -> 75 bp复杂序列 -> L3(GCC，含7 bp插入支路) -> 8 bp尾部`

## 如何读取正式 GFA

- `H` 行记录评分参数：`PM` 为匹配概率，`PI` 为 indel 概率，`MC` 为最小成环次数，`MD` 为最小重复密度。
- `S` 行的 `LC:Z:L1/L2/L3` 表示节点属于哪个位置环；`LC:Z:B1/B4/B6` 表示复杂或侧翼 block。
- `BT:Z:exact_motif` 表示主体 motif 节点。
- `BT:Z:variant_motif` 表示一个碱基替换形成的变异 motif，`CA` 给出对应主体 motif，`ED:i:1` 表示编辑距离为 1。
- `BT:Z:loop_insertion` 表示环内部显式插入序列。
- `L` 行的 `RL:i:1` 标记真实自环边，`PS` 是观察到该有向边的路径转移支持数。
- 每条 `P` 路径带有 `L1/L2/L3` 标签，格式为 `copies=...;variants=...;inserted_bp=...`，可直接读取该路径在三个位置环上的循环次数和复杂情况。

GFA 中共有 18 个节点、29 条不同有向边和 6 条自环边；L1、L2、L3 均具有独立自环实例。

## PNG 阅读

- `多环结构总览.png` 展示群体共同的结构骨架。环内箭头表示同一 motif 节点可重复经过，环下方数字是 47 条路径上的次数范围。
- `路径block图.png` 每一横行代表一条路径。绿色为 GCC-like，蓝色为 CAG-like，灰色为复杂/插入序列；斜线表示含变异 motif，交叉线表示重复段中还包含插入。
- block 图中重复块宽度按 motif 单元数表达，灰色块为了可读性按 `bp/9` 缩放，所以横轴不能直接当作统一的碱基坐标尺。
- 精确数值应以 `逐路径环次数矩阵.tsv` 和 `逐路径环统计.tsv` 为准。

## 输出文件

- `路径汇总.tsv`：每条路径的 VNTR 总体统计。
- `block明细.tsv`：每个 block 的坐标、序列、motif 一致性、TRF 对数似然、变异和插入。
- `主体motif证据.tsv`：主体 motif 与变异 motif 的群体支持。
- `TRF周期候选.tsv`：所有通过阈值的周期候选；`selected=1` 为正式采用的 3 bp 候选。
- `多环目录.tsv`：L1/L2/L3 的群体汇总。
- `逐路径环统计.tsv`：长表形式的 141 个路径-环组合。
- `逐路径环次数矩阵.tsv`：每条路径一行，横向比较 L1/L2/L3。
- `正式位置特异多环图.gfa`：正式多环图。
- `路径block图.png` 与 `多环结构总览.png`：两种尺度的可视化。
- `验证汇总.tsv`：节点、边、自环和重建检查结果。

## 验证结果

- 路径数：47；路径-环组合数：141。
- L1/L2/L3 均由 47 条路径支持，正式选择的周期全部为 3 bp。
- 47/47 条路径均通过 atom、block 和正式 GFA 节点序列的逐碱基重建。
- 所有正式重复 block 均满足最小次数与重复密度阈值。
- 每条 GFA 路径均实际经过 L1、L2、L3 三个独立节点命名空间。
