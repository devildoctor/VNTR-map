# 20260825 P2：从头发现主体 motif 与服务器完整验证

## 目标与边界

本版解决方案文档中的 P2“自动发现主体 motif”。P1 的唯一侧翼与共识 VNTR 外边界继续作为输入，但 P2 不读取预设的 `CAG/GCC` motif 字典。

当前实现解决：

- 在 P1 左右唯一侧翼限定的同源窗口中进行 1–18 bp de novo k-mer/motif 搜索。
- 优先选择最短 primitive motif；循环移位和反向互补归并到同一 canonical family。
- 使用跨路径支持和最小描述长度（MDL）选择共享主体字典。
- 对可由短周期无限重复解释的长滑动 k-mer做遮蔽；AB/ABC 只作为高阶候选报告，不覆盖 primitive family。
- 从 P1 共识起点按共享周期固定相位确定主体核心，再处理边缘变异和局部插入。
- 输出 de novo motif 标注 GFA，并逐路径保留 3 个位置区块的次数、变异和插入。

当前没有解决：

- R3 中 motif-like 插入的唯一生物学解释。仅凭组装序列，4 bp 插入加更多变异 motif 与 7 bp 插入加较少变异 motif 接近等价。本版使用 MDL 最优解并标为 sequence-only 暂定结果，最终需 reads 和外部工具确认。
- 半马尔可夫持续长度、posterior 和第二优解属于 P3。
- read-backed 真伪变异判定属于 P4。

## 依据

实现参考了 MotifScope 的多样本 de novo k-mer motif 发现思路，以及 uTR 对复杂/镶嵌重复采用较少、较短生成单元进行简约分解的思想：

- MotifScope: <https://genome.cshlp.org/content/early/2024/11/13/gr.279278.124>
- complex TR / uTR: <https://www.nature.com/articles/s41467-023-41262-1>
- uTR code: <https://github.com/morisUtokyo/uTR>

## IRF2BPL 当前结果

- 共享 primitive family：`M1=AGC`、`M2=CCG`，周期均为 3 bp，支持均为 47/47。
- `AGC` family 包含 `AGC/CAG/GCA/CTG/GCT/TGC`。
- `CCG` family 包含 `CCG/CGC/CGG/GCC/GCG/GGC`。
- MDL：背景模型 `23554.00 bits`，选中字典后 `15050.50 bits`，减少 `8503.50 bits`。
- 47/47 路径均得到 3 个位置区块，顺序为 `M2 -> M1 -> M2`。
- GFA 为 30 余个节点、40 余条边，R1/R2/R3 均有显式自环；47/47 路径逐碱基重建成功。
- 当前次数范围：R1 12–16，R2 19–32，R3 15–20。R3 小复杂分解仍需 reads 验证。

## 输出

- `*_de_novo_motif候选.tsv`：全部候选、跨路径支持、composite/短周期遮蔽与 MDL 入选状态。
- `*_共享motif字典.tsv`：正式 primitive family 字典。
- `*_逐路径motif_token.tsv`：exact motif、variant motif 和复杂/插入 token。
- `*_逐路径repeat区块.tsv`：R1/R2/R3 的边界、次数、变异和插入。
- `*_高阶重复候选.tsv`：AB/ABC 高阶候选；当前 IRF2BPL 为空是正常结果。
- `*_逐路径motif矩阵.tsv`：每条路径一行的区块比较表。
- `*_P2_de_novo_motif图.gfa`：P2 位置特异多环图。
- `*_P2_motif与区块总览.png`：共享字典支持和 47 条路径区块图。
- `*_P2验证汇总.tsv`：MDL、稳定性、区块数、环和重建指标。

## Linux 服务器迁移

推荐新建独立 worktree，不覆盖服务器上原有环境和结果：

```bash
cd ~/projects/VNTR-map
git fetch origin
git worktree add ../VNTR-map-20260825-P2 origin/20260825-P2
cd ../VNTR-map-20260825-P2
conda activate vntrmap
bash "程序/20260825_Linux服务器P1P2完整验证.sh"
```

默认输出到 `outputs/IRF2BPL/20260825_linux_P1P2_full_validation/<UTC时间>/`。脚本依次运行 P1、P2、两个回归测试，核对关键指标并生成 SHA-256 清单。

## 完整验证判定

只有以下项目同时通过，才可认为代码迁移验证完成：

1. P1 左右唯一锚点、内部边界和 GFA 重建均为 47/47。
2. P2 自动选中两个 3 bp primitive family，且输入路径倒序不改变字典。
3. 47 条路径全部输出 3 个位置区块，共 141 个 path-block 组合。
4. R1/R2/R3 均形成显式自环，P2 GFA 重建为 47/47。
5. 合成测试通过循环移位、反向互补、明确插入和 ABAB 高阶候选。
6. 服务器保存软件版本、日志、验证汇总和 SHA-256 清单。
