# VNTR-map 统一调用器使用说明

## 1. 文件与定位

- 调用器：`程序/20260826_VNTR功能统一调用器.py`
- 功能注册表：`程序/20260826_VNTR功能注册表.json`
- 回归测试：`tests/20260826_VNTR统一调用器回归测试.py`

调用器不复制 P1-P5 的算法代码，只负责依赖解析、命令生成、日志记录、产物检查和断点续跑。Windows 与 Linux 使用同一份程序。

## 2. 查看现有功能

```bash
python -u "程序/20260826_VNTR功能统一调用器.py" list
python -u "程序/20260826_VNTR功能统一调用器.py" describe P3
```

`list` 显示功能、依赖和简要说明；`describe` 显示参数模板、输出和必需产物。

## 3. 完整运行 P1-P5

```bash
python -u "程序/20260826_VNTR功能统一调用器.py" pipeline \
  --input "测试数据/IRF2BPL.HPRC.fa.3034e58.11fba48.904d69e.smooth.final.gfa" \
  --outdir "outputs/IRF2BPL/20260826_统一调用器完整运行" \
  --prefix "IRF2BPL"
```

输出目录固定分为 `P1` 至 `P5` 子目录。每个阶段使用 `IRF2BPL_P1`、`IRF2BPL_P2` 等独立前缀，避免同名文件覆盖。

运行根目录还会生成：

- `run_manifest.json`：完整命令、输入、产物、阶段状态和验证指标。
- `run_attempts/*.json`：每次执行或断点续跑的独立历史清单；不会被下一次运行覆盖。
- `stage_status.tsv`：适合快速查看或脚本读取的状态表。
- `P1.log` 至 `P5.log`：标准输出与错误日志。
- `SHA256SUMS`：本次结果文件的 SHA-256 清单。
- `.matplotlib/`：本次运行独立的字体缓存，避免服务器 HOME 权限问题。

## 4. 常用运行方式

### 4.1 只看命令，不执行

```bash
python -u "程序/20260826_VNTR功能统一调用器.py" pipeline \
  --input input.gfa \
  --outdir outputs/dryrun \
  --prefix sample \
  --dry-run
```

### 4.2 只运行 P1-P3

```bash
python -u "程序/20260826_VNTR功能统一调用器.py" pipeline \
  --input input.gfa \
  --outdir outputs/sample_run \
  --prefix sample \
  --to-stage P3
```

也可以用 `--stages P1,P2` 明确选择阶段。若选择非连续阶段，必须用 `--artifact` 提供未在本次运行中生成的依赖产物。

### 4.3 断点续跑

```bash
python -u "程序/20260826_VNTR功能统一调用器.py" pipeline \
  --input input.gfa \
  --outdir outputs/sample_run \
  --prefix sample \
  --resume
```

只有注册表声明的全部必需产物都存在且非空时，阶段才会标记为 `skipped_existing`。程序退出码为 0 但必需产物缺失时，会标记为 `missing_output`。

### 4.4 覆盖某一阶段参数

```bash
python -u "程序/20260826_VNTR功能统一调用器.py" pipeline \
  --input input.gfa \
  --outdir outputs/sample_run \
  --prefix sample \
  --set-param P1.anchor-k=25 \
  --set-param P3.path-weight-mode=suffix \
  --set-flag P4.no-require-both-strands
```

`--set-param STAGE.PARAM=VALUE` 和 `--set-flag STAGE.FLAG` 都可重复使用。

### 4.5 加入外部边界或 read 证据

```bash
python -u "程序/20260826_VNTR功能统一调用器.py" pipeline \
  --input input.gfa \
  --outdir outputs/sample_run \
  --prefix sample \
  --external-evidence external_boundaries.tsv \
  --read-evidence read_evidence.tsv
```

外部边界证据只传给 P1，逐 read 证据只传给 P4。

### 4.6 直接调用单个程序

```bash
python -u "程序/20260826_VNTR功能统一调用器.py" stage P1 -- \
  --input input.gfa \
  --outdir outputs/P1_only \
  --prefix sample_P1
```

`--` 后的参数原样传给 P1。此模式适合调试；正式分析建议使用 `pipeline`，因为后者会记录产物、状态和校验和。

## 5. 使用已有 P3 结果运行 P4-P5

```bash
python -u "程序/20260826_VNTR功能统一调用器.py" pipeline \
  --input input.gfa \
  --outdir outputs/P4P5_run \
  --prefix sample \
  --stages P4,P5 \
  --artifact P3.gfa=/absolute/path/sample_P3_P3半马尔可夫多环图.gfa \
  --artifact P3.tokens=/absolute/path/sample_P3_逐路径token后验.tsv \
  --artifact P3.blocks=/absolute/path/sample_P3_逐路径P3_repeat区块.tsv \
  --read-evidence /absolute/path/read_evidence.tsv
```

`--artifact` 的键必须与注册表中的 `阶段ID.产物名` 一致。

## 6. 增加未来功能

在 `20260826_VNTR功能注册表.json` 的 `stages` 中追加对象即可。最小结构如下：

```json
{
  "id": "P6",
  "name": "新功能名称",
  "description": "该功能解决的问题",
  "depends_on": ["P5"],
  "command": ["${python}", "-u", "${repo}/程序/P6程序.py"],
  "arguments": [
    {"flag": "--input", "value": "${artifact.P5.gfa}"},
    {"flag": "--outdir", "value": "${stage_dir}"},
    {"flag": "--prefix", "value": "${stage_prefix}"}
  ],
  "outputs": {
    "gfa": "${stage_dir}/${stage_prefix}_P6图.gfa",
    "validation": "${stage_dir}/${stage_prefix}_P6验证汇总.tsv"
  },
  "required_outputs": ["gfa", "validation"]
}
```

可用模板变量包括：

- `${repo}`：仓库根目录。
- `${python}`：当前指定的 Python。
- `${input}`：主输入 GFA。
- `${run_dir}`、`${stage_dir}`、`${stage_prefix}`。
- `${artifact.P5.gfa}`：前序阶段登记的具体产物。
- `${read_evidence}`、`${external_evidence}`：可选证据路径。

`command` 使用参数数组，不通过 shell 拼接，因此中文路径、空格路径和用户参数不会被错误拆词。

## 7. 状态解释

- `completed`：退出码为 0，所有必需产物存在且非空。
- `skipped_existing`：启用 `--resume`，已有必需产物完整。
- `planned`：dry-run 中已成功解析命令。
- `failed`：程序返回非零退出码。
- `missing_output`：程序返回 0，但必需产物缺失。
- `missing_input`：依赖产物路径存在于清单，但文件缺失。
- `configuration_error`：模板变量或注册配置不完整。
- `blocked`：依赖阶段失败，当前阶段不能执行。

## 8. 回归测试

```bash
python -m unittest "tests/20260826_VNTR统一调用器回归测试.py" -v
```

测试覆盖注册表依赖顺序、完整 dry-run 产物传递、依赖循环拒绝，以及“退出码为 0 但产物缺失”的失败判定。
